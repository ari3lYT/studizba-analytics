# Studizba Analytics

[English](README.md) · **Русский**

Самостоятельно размещаемый исторический сборщик, аналитический движок, панель, REST API и MCP-сервер для публичных отзывов о преподавателях МГТУ на Studizba.

Проект сохраняет исходные снимки, отслеживает редакции вместо перезаписи, рассчитывает метрики преподавателей и кафедр с учётом достоверности и показывает каждую оценку вместе с доказательствами и метаданными формулы.

## Что входит

- адаптивный асинхронный сбор кафедр, карточек преподавателей и страниц отзывов;
- gzip-снимки источников, идентифицируемые по SHA-256;
- история снимков преподавателей, версий отзывов, обходов и расписаний в PostgreSQL;
- русский полнотекстовый и триграммный поиск с расширением синонимов предметной области;
- необязательный структурированный анализ отзывов через OpenAI-совместимый API;
- проверка доказательств, отклоняющая цитаты модели, которых нет в исходном отзыве;
- взвешивание по достоверности, временному затуханию, байесовскому сглаживанию, поляризации и покрытию кафедры;
- панель FastAPI и OpenAPI;
- MCP-серверы через stdio и Streamable HTTP;
- явные операции обновления и наблюдаемый фоновый прогресс.

## Архитектура

```text
Studizba HTML/AJAX
        │
        ▼
асинхронный сборщик ── gzip-снимки ── журнал изменений / адаптивное расписание
        │
        ▼
PostgreSQL + pg_trgm + русский FTS
        │
        ├── необязательный LLM-адаптер → проверенные структурированные доказательства
        ├── статистическая агрегация → метрики преподавателей/кафедр
        ├── панель FastAPI и REST API
        └── MCP-сервер
```

## Быстрый старт

Требования: Python 3.10+, PostgreSQL 16+ и Docker Compose, если нужна включённая служба базы данных.

```bash
git clone https://github.com/ari3lYT/studizba-analytics.git
cd studizba-analytics
cp credentials.example.json credentials.local.json
chmod 600 credentials.local.json
docker compose up -d postgres
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/studizba init-db
```

Учётные данные также можно передать через `STUDIZBA_USERNAME`, `STUDIZBA_PASSWORD`, `GLM_API_KEY`, `GLM_MODEL`, `GLM_BASE_URL` и `DATABASE_URL`.

Начните с небольшой проверочной выборки:

```bash
.venv/bin/studizba bootstrap --details-limit 10
.venv/bin/studizba status
```

Затем запустите возобновляемый полный сбор и агрегацию:

```bash
.venv/bin/studizba bootstrap
.venv/bin/studizba analyze --limit 200 --concurrency 3
.venv/bin/studizba aggregate
```

После ошибок сборщик увеличивает задержку и постепенно реже обновляет неизменившиеся страницы. Исходные снимки позволяют повторно применять изменения парсера и аналитики без новых запросов к источнику.

## Службы

```bash
.venv/bin/studizba serve-dashboard --host 127.0.0.1 --port 8898
STUDIZBA_ROOT="$PWD" .venv/bin/studizba-mcp
STUDIZBA_ROOT="$PWD" .venv/bin/studizba-mcp-http
```

Примеры systemd и nginx находятся в `deploy/`. Перед установкой проверьте пути, пользователей, порты и контроль доступа.

## Возможности MCP

MCP предоставляет поиск преподавателей, кафедр и отзывов, объяснение оценок, рейтинги, сравнения, историю, последние изменения, состояние мониторинга и явные операции обновления.

Оценки не возвращаются необъяснимыми числами: `explain_score` включает версию формулы, размер выборки, покрытие, достоверность, даты, исходные URL и проверенные фрагменты доказательств.

## Тесты

```bash
.venv/bin/pytest -q -m 'not live'
```

В репозитории хранятся только небольшие синтетические страницы. В нём намеренно нет производственных отзывов, cookie сессий, учётных данных, дампов базы или состояния обхода. Живые тесты изолированы маркером `live`.

## Ответственное использование

- Соблюдайте условия исходного сайта, его robots-политику и допустимую нагрузку.
- Используйте низкую параллельность и сохраняйте адаптивные задержки.
- Относитесь к отзывам как к субъективным сообщениям, а не установленным фактам о человеке.
- Не публикуйте учётные данные, состояние сессии или приватные данные.
- Перед открытием операций обновления или анализа недоверенным пользователям добавьте аутентификацию и ограничения частоты запросов.
